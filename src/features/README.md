# Product Feature Boundaries

This folder is reserved for domain modules as TalentIQ moves from a hackathon frontend to a production application.

- candidate: identity, profile, career roadmap, and interview history
- recruiter: talent search, shortlists, comparisons, and hiring pipeline
- verification: evidence sources and trust status
- matching: role-fit signals and ranking
- analytics: hiring and talent-pool insights

The current demo keeps page compositions in src/screens and route definitions in src/routes so the build stays lightweight and easy to judge.
